# Blazor DBZ - Personagem

Atividade da disciplina Usabilidade, Desenvolvimento Web, Mobile e Jogos.

Aplicação Blazor Server em .NET 10 para pesquisar personagens da API pública Dragon Ball pelo ID e mostrar nome, planeta de origem e transformações.

## Executar

Com o SDK .NET 10 instalado, execute `dotnet run` na pasta do projeto e abra o endereço local indicado no terminal.

## API

`https://dragonball-api.com/api/characters/1`

A aplicação consulta o ID informado pelo usuário, trata respostas não encontradas e falhas de conexão.
